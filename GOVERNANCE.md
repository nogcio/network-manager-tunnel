# Governance

The project follows an owner-led model. There is no elected council, established
maintainer team or configured public release authority.

- Substantial changes start with a proposal; durable decisions use ADRs.
- The owner reviews scope, dependency admission, privilege and release policy.
- Passing CI does not imply design acceptance or permission to publish.
- Disclose conflicts of interest; self-review is not independent approval.
- Repository administration, private reporting and publication need separate setup.

See [contributing](CONTRIBUTING.md) and [security](SECURITY.md).
